# Contributing to Awesome Claws 🦞

## Addition Guidelines

- **Agents only**: Communities for agent builders/swarmers (Discords, hubs, forums).
- **Active & agentic**: No dead links or generic AI chats.
- **Format**: Table rows or bullets. Include Discord invite if applicable.
- **No self-promo**: Prove value first.

## Workflow

```bash
git clone https://github.com/mi4m/awesome-claws.git
cd awesome-claws
# Edit README.md
git add .
git commit -m "🦞 Add [Community Name]"
git push
gh pr create
```

Stale PRs auto-close. Chaos welcome.
